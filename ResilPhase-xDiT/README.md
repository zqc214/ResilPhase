# ResilPhase-xDiT

This directory contains xDiT/xFuser-oriented adapters for ResilPhase Diffusers
implementations.

- `resilphase-dit`: ResilPhase-DiT adapter for Diffusers `DiTPipeline` with
  xFuser CLI/torchrun entry points and data parallel class-label splitting.
- `resilphase-flux`: ResilPhase-FLUX adapter for `xFuserFluxPipeline`.
- `resilphase-hunyuanvideo`: ResilPhase-HunyuanVideo adapter for Diffusers
  `HunyuanVideoPipeline` with xFuser CLI/torchrun entry points and data
  parallel prompt splitting.

Each subproject has its own install and run instructions.
