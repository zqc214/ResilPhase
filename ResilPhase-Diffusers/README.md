# ResilPhase-Diffusers

This directory contains ResilPhase integrations for HuggingFace Diffusers.

Available plugins:

- `resilphase-flux`: ResilPhase-FLUX acceleration patch for Diffusers FLUX pipelines.
- `resilphase-dit`: ResilPhase-DiT acceleration patch for Diffusers DiT pipelines.
- `resilphase-hunyuanvideo`: ResilPhase-HunyuanVideo acceleration patch for Diffusers HunyuanVideo pipelines.
